What it is

BlackNode Launcher is a system shell built for the phone. It gives you a home screen, notes, recents and a set of factory programs in one place. It is a separate product from Lumen.

Key features
  • HomeA phone-first home screen for your programs.
  • NotesQuick notes built into the shell.
  • RecentsJump back into what you opened last.
  • Factory programsA starter set of built-in programs.
