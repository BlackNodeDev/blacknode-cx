What it is

UmiShell is a command shell with AI built in, running locally. Every action goes through allow / ask / deny rules, secrets live in an on-device vault, and every event is recorded in a hash-chained audit log.

Key features
  • Allow / ask / denyEach command is gated by a rule you control.
  • On-device vaultKeys and secrets stay local.
  • Hash-chained audit logA tamper-evident record of what ran.
