What it is

BlackLlama is an AI chat app that ships as a single file. It remembers locally, can generate images if you want, searches Wikipedia and previews HTML in a sandbox.

Key features
  • Single fileThe whole app in one HTML file.
  • Local memoryConversation memory stays on your device.
  • Wikipedia searchPull facts in mid-conversation.
  • Sandboxed previewRender generated HTML safely.
