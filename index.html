02 · How it works

Five teammates, one pipeline.

Every Core build passes through the same five bots. Each one owns a stage, and you can see what each did in the Bots tab.

STAGE 01

Architect

PLAN

Reads your request and the project. With Plan Review on, it shows a plan first.

STAGE 02

Compiler

CODE

Writes complete files with the live AI. No snippets, no placeholders.

STAGE 03

Security

REVIEW

Scans for API keys, TODOs, stubs, untyped code and risky calls.

STAGE 04

Triage

TEST

Parses every script and runs web apps in a hidden phone-sized sandbox. If it breaks, Triage sends it back for one repair.

STAGE 05

Launch

SHIP

Packages the result and waits at the Approval Gate for you.

→ Then keep chatting: “add a dark mode”, “make it faster”↓ Download the file or export the whole project
03 · Guardrails

Real checks, not promises.

These run in your browser on every build. Flip them in Core’s Bots tab and the next build changes.

Approval Gate

Builds wait as a draft with Preview, Code and Apply. Nothing touches your project until you say so.

Secret scan

API keys, tokens and hardcoded passwords hold the build before it can be saved.

Zero-TODO

TODO, FIXME and stub functions count as errors, so unfinished code can’t slip through.

412px smoke test

Web apps run in a hidden phone-width sandbox. Runtime errors and sideways overflow are caught before Preview.

Strict typing

Godot and Python code must be typed. Every function, every parameter.

Your device, your keys

Projects and chats stay in your browser. If you add your own API key, it is only sent to the provider you chose and never exported.

04 · Engines

Free by default. Yours if you want.

Both apps work the moment they open. Switch engines any time in settings.

DEFAULT

Free Live AI

A real reasoning model served free by pollinations.ai. No key, no sign-up. It’s a shared service, so busy times can be slower.

IN-BROWSER

On-Device Offline AI

A small open model (SmolLM2 or Qwen2.5) downloads once and runs inside your browser with WebGPU or CPU. Works offline. Best for lighter jobs.

BYO KEY

Your own provider

Plug in an xAI Grok key, a free key from Groq, Gemini or OpenRouter, or point at Ollama (Termux), LM Studio or any OpenAI-compatible URL.

OFFLINE

Offline Starter

In Core only: a template generator that works with no connection. Clearly labelled, never passed off as AI.
